# AO Armor Packs v1.0.0

The first public release of optional Omni-Armed Forces armor artwork and live
armor switching for the regular Anarchy Online new-engine client.

## Download

Download **[AO-Armor-Packs-v1.0.0.zip](https://github.com/zooraw/ao-armor-packs/releases/download/v1.0.0/AO-Armor-Packs-v1.0.0.zip)** below.
It includes all custom artwork, the companion, PowerShell installers and guides.
`SHA256SUMS.txt` contains the download checksum. No Git installation is needed.

## Install

Requirements: Windows, the supported regular **AO 18.8.62_EP2 new-engine** DLL
build, an installed [AOU GUI](https://github.com/zooraw/aou_mod), and Python
**3.13 or 3.14** available as `python`. Internet is needed for initial dependencies.

1. Close AO normally and **Extract All** from the ZIP to a permanent folder.
2. Open **INSTALL.md** in that folder. Find your game folder, AO AppData `Gui`
   folder and account `Prefs.xml` using its instructions.
3. Open PowerShell in the folder containing `Install.ps1` and run it with your
   paths. The following are generic examples to replace:

   ```powershell
   .\Install.ps1 -GamePath 'C:\Games\Anarchy Online' -GuiPath 'C:\LocalPrefs\Gui' -PreferencesPath 'C:\LocalPrefs\Prefs\Account\Prefs.xml'
   ```

4. Use the **AO Armor Packs** desktop shortcut and log in normally. Open
   **AOU > Armor Packs** or **F10 > Armor Packs**. Checked selects custom art;
   unchecked restores original art. Helmet/body and tank switch independently.

**[Full installation instructions](https://github.com/zooraw/ao-armor-packs/blob/v1.0.0/INSTALL.md)**
or **[install with an AI assistant](https://github.com/zooraw/ao-armor-packs/blob/v1.0.0/INSTALL_WITH_AI.md)**.
Both guides are included in the ZIP. Keep the extracted folder in place.

## Included

- Matte charcoal/black Omni-Armed Forces helmet/body with blood-red glass
  visor/logos; no yellow on the helmet.
- Black/yellow Tank Armor with light wear and a red logo.
- Independent live switches; cached uploads are refreshed on every transfer,
  including the return to original art.
- Armor controls added only by the separately installed pack and removed on
  uninstall. The base AOU mod has no permanently visible armor controls.
- Isolated dependencies, local stock extraction, native database verification
  and an uninstall path with ownership checks.

## Verification and removal

A fresh installation passed all eight native texture lookup/hash checks. The
user confirmed that checking and unchecking both armor groups works, including
restoring original artwork. Seven focused tests and a cached-upload contract
model also passed. Full uninstall, zoning and device-reset runtime coverage
remain unobserved; see the [verification notes](https://github.com/zooraw/ao-armor-packs/blob/v1.0.0/docs/verification.md).

To remove it, close AO and run `Uninstall.ps1` from the extracted folder. Keep
real configuration, generated textures, backups and logs local. This download
contains no account details, private deployment settings or original game records.
